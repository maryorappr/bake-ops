# Cookie Ops - Phase 1 PRD

## Goal
Run day-to-day cookie operations: Google Forms orders, fulfillment workflow, dashboard metrics, inventory + COGS.

## Phase 1 Modules
- Google Forms ingestion (via Google Sheets sync path)
- Orders + fulfillment board
- Dashboard KPIs
- Inventory + recipe-based costing
- Dockerized local deployment

## User Roles
- admin
- ops

## Core Screens
- Dashboard
- Orders to Fulfill
- Inventory
- Products/Recipes

## MVP Success Criteria
- New form submissions appear as orders within 5 minutes.
- Orders can move through statuses: new, prep, ready, fulfilled.
- Dashboard shows today's due orders, weekly revenue, low stock alerts.
